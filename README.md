# محفظة الالتزام للمشاريع للمقاولين

منصة لمتابعة التزام المقاولين بأوامر عملهم: الحصر والمقايسة والمواد وضبط الحماية والإحداثيات والنماذج والفواتير،
مع **إرسال التقارير بالبريد من كل صفحة** و**قوائم بريد** يديرها مدير النظام.
أُعيد بناؤها من الملف المرجعي الواحد (`reference/legacy.html`) إلى نظام كامل: واجهة + API + قاعدة بيانات،
بنفس الصفحات والمنطق والحسابات والنصوص والهوية البصرية، وبالعربية والإنجليزية.

> عند أي تعارض بين هذا المشروع والمنصة القديمة، المرجع هو `reference/legacy.html`.

## التشغيل بأمر واحد

```bash
cp .env.example .env        # اختياري: للتخصيص (كل شيء له قيمة افتراضية للتجربة)
docker compose up --build
```

ثم افتح **http://localhost:5173** — صندوق البريد التجريبي (MailHog) على http://localhost:8025 والوثائق التفاعلية للـ API على http://localhost:5173/api/docs.

| الحساب | المستخدم | كلمة المرور الأولية | الدور |
|---|---|---|---|
| مدير النظام | `ahmed` | `Admin@12345` | كل الصلاحيات |
| مدير قسم | `salem` | `Dept@12345` | كل الصفحات عدا المستخدمين |
| مدير مشاريع | `hamad` | `Pm@12345` | عرض/إضافة/تصدير بلا حذف ولا استيراد |

> هذه كلمات تجريبية. غيّرها قبل أي استخدام حقيقي بضبط `SEED_*_PASSWORD` في `.env` قبل أول إقلاع، أو من صفحة «المستخدمون والصلاحيات».
> تبدأ كل جلسة **مقفلة للتعديل**؛ يُفتح القفل بكلمة مرور مدير النظام (زر 🔒 أعلى الصفحة).

الخدمات: `web` (nginx: الواجهة + تمرير `/api`) · `api` (Fastify + Chromium لتوليد PDF) · `postgres` · `mailhog`.

## التشغيل المحلي بلا docker

```bash
npm install
bash scripts/dev-pg.sh start        # PostgreSQL محلي على 5432 (أو استعمل أي قاعدة وضع رابطها في DATABASE_URL)
cp .env.example .env
npm run dev:api                      # الخادم على :3000 (يطبّق الهجرات ويزرع المستخدمين تلقائيًا)
npm run dev:web                      # الواجهة على :5173 مع تمرير /api
```

## البنية

```
apps/web        الواجهة (Vite + TypeScript، بلا إطار) — RTL افتراضيًا، EN/AR، وضع ليلي، طباعة نظيفة
apps/api        Fastify 5 + Drizzle ORM + PostgreSQL + طابور pg-boss — كل المسارات تحت /api/v1
packages/core   منطق المنصة النقي: الاستنباط، الاستيراد، هوية أمر العمل، الإحداثيات، الحسابات (يشاركه الخادم والواجهة)
integrations/   ملفات n8n وتوثيق المفاتيح والـ webhooks
e2e/            اختبار تشغيل كامل بـ Playwright (+ خادم SMTP وهمي)
reference/      المنصة القديمة (المرجع)
docker/         Dockerfile للـ api والـ web وإعداد nginx
```

**كيف ضمنّا التطابق مع المنصة القديمة؟** شُغّلت المنصة القديمة داخل jsdom وسُجّلت مخرجاتها
(`packages/core/test/golden/*.json`): أرقام مشروع الحصينية، كل الصفحات بالعربية والإنجليزية، الشرائح، ملفات التصدير، ومحرك الاستيراد.
اختبارات `packages/core` تقارن الحزمة الجديدة بها، واختبارات `apps/web` تقارن **HTML كل صفحة وكل شريحة حرفيًا**.
الفروق الوحيدة المقصودة موثّقة في `apps/web/test/parity.test.ts` (الشعار صار ملفًا، وأصول الملفات والذكاء الاصطناعي صارا على الخادم).
دوال العرض المنقولة تحمل `// @ts-nocheck` عمدًا (نقل حرفي)، ويفحص `apps/web/scripts/check-names.mjs` أن كل اسم فيها معرّف.

## المتغيرات (`.env`)

كل شيء من البيئة، ولا أسرار في الكود. القائمة الكاملة بشروحها في [`.env.example`](.env.example). أهمها:

| المتغير | الغرض |
|---|---|
| `DATABASE_URL`, `JWT_SECRET`, `WEBHOOK_SECRET` | قاعدة البيانات والأسرار (يرفض الخادم القيم الافتراضية عند `NODE_ENV=production`) |
| `MAIL_PROVIDER` | `smtp` (افتراضي) أو `resend` أو `gmail_api` — الإرسال من الخادم فقط |
| `SMTP_*`, `MAIL_FROM`, `RESEND_API_KEY`, `GMAIL_*` | إعدادات المزوّد المختار |
| `ADMIN_EMAIL` | مستلم **إلزامي** لكل تقرير (`az3919131@gmail.com`): يُضاف برمجيًا ولا يُحذف ولا يُعطَّل لا من الواجهة ولا من الـ API |
| `REPORT_MAX_ATTACH_MB` | المرفق الأكبر يتحول إلى رابط تنزيل موقّع صالح 7 أيام |
| `STORAGE_PROVIDER` | `local` أو `s3` لأصول الملفات والمرفقات |
| `ANTHROPIC_API_KEY` | تفعيل «محفظة Ai» (Claude من الخادم؛ لا مفتاح في المتصفح). بدونه تعمل المنصة كاملة |
| `PDF_RENDER_BASE_URL`, `CHROMIUM_PATH`, `DISABLE_PDF` | توليد PDF بـ Chromium |

## الميزتان الجديدتان

### ✉ إرسال التقرير (في كل صفحة)
زر يظهر **فقط لمن يملك صلاحية التصدير** في الصفحة. يفتح نافذة تأكيد فيها المستلمون النشطون (مدير النظام بعلامة 🔒)،
خيارات PDF وExcel، ملاحظة اختيارية، «إرسال الآن»، «إدارة المستلمين»، ثم **حالة كل مستلم** بعد الإرسال.
- `POST /api/v1/reports/:reportKey/send` ← `202 {jobId}` · `GET /api/v1/reports/jobs/:jobId` · `GET /api/v1/reports/:reportKey/preview`
- طابور غير متزامن بثلاث محاولات وتأخير متزايد، وإزالة تكرار العناوين بلا حساسية لحالة الأحرف، وحد أقصى 50 مستلمًا.
- الموضوع: `[محفظة الالتزام] {التقرير} — {المشروع} — W/O {رقم}`؛ الجسم RTL بـ 4–6 أرقام رئيسية ثم توقيع `Project manager · Eng. Ahmed Zahran` ثم «أُرسل تلقائيًا من محفظة الالتزام».
- PDF يُولَّد بطباعة **صفحة الواجهة نفسها** (Chromium، A4 أفقي)، وExcel بـ ExcelJS (RTL، رأس مجمّد، أرقام حقيقية).
- حارس أمر العمل: لا يُرسل تقرير مشروع إلا لمن له صلاحية على مقاول المشروع. تقريرا المستخدمين وقوائم البريد لمدير النظام فقط.

### قوائم البريد (`/emails` — صفحة «قوائم البريد»)
بطاقات الملخص، إضافة بتحقق RFC ورسائل عربية، إضافة جماعية (لصق/CSV/Excel)، جدول بمفتاح تفعيل وتاريخ الإضافة ومن أضاف وآخر تقرير،
صف مدير النظام 🔒 (الاسم فقط قابل للتعديل)، مصفوفة نطاق التقارير لكل مستلم، رسالة اختبار لكل مستلم/للجميع،
سجل الإرسال مع إعادة المحاولة، مؤشر صحة المزوّد، وجدولة أسبوعية/شهرية (cron بتوقيت الخادم `TZ`).

## الأمان

- المصادقة والصلاحيات وقفل التعديل وعزل المقاولين **تُفرض على الخادم** في كل طلب: JWT قصير (15 دقيقة) + كوكي تحديث `httpOnly`، وكلمات المرور argon2id، وتحديد معدل الطلبات، وإغلاق الحساب بعد 5 محاولات فاشلة.
- الجلسة تنتهي بإغلاق التبويب، وكل زيارة جديدة تبدأ بشاشة الدخول.
- تغيير كلمة المرور برمز من 6 أرقام يُرسل إلى `ADMIN_EMAIL` (صالح 30 دقيقة، 5 محاولات).
- سجلات الخادم لا تطبع كلمات مرور ولا رموز تحقق ولا ترويسات المصادقة.
- nginx يضبط CSP صارمة (بلا سكربتات مضمّنة) ورؤوس أمان.

## الاختبارات

```bash
npm run typecheck     # core + api + web (ويفحص أسماء الدوال المنقولة)
npm test              # Vitest: core (48) + api (49) + web parity (22)
npm run test:e2e      # Playwright: دخول ← رفع ← استنباط ← إرسال تقرير ← وصوله لمدير النظام وللمستلم المضاف + فحص WCAG 2.1 AA بـ axe
```

اختبار E2E يشغّل المكدّس بنفسه (قاعدة بيانات نظيفة + خادم SMTP وهمي) ولا يحتاج docker. على docker compose:

```bash
E2E_BASE_URL=http://localhost:5173 MAILHOG_URL=http://localhost:8025 npm run test:e2e
```

## التكاملات

مفاتيح API بنطاقات (`read:projects` · `write:imports` · `send:reports`)، webhooks صادرة موقّعة HMAC-SHA256 (`X-Signature`)،
webhook وارد `/api/v1/hooks/import`، ملفا n8n (تقرير كل أحد 8 صباحًا، واستيراد ملف)، وواجهات `ErpAdapter` و`StorageProvider` و`MailProvider`.
التفاصيل: [`integrations/README.md`](integrations/README.md).

## ملاحظات صريحة

  (`docker compose config`) ومن تشغيل حزمة الخادم الإنتاجية بالاعتماديات الإنتاجية فقط، لكن أول `docker compose up --build` على جهازك هو أول بناء فعلي للصور.
